D流体纸页

无固定时长 spring 物理 · 可中断、速度交接 · 指示器/抽屉带过冲跟手感（预览用曲线近似）

方向说明（时值表 / 落地方式 / 代价）

A · 静默纸面

气质：像换了一张纸——没有东西在「动」，只是内容换了。最贴报纸的冷静。

时值：tab crossfade 150 · 阅读器 160 · 抽屉 140 · 指示器 150ms。

落地：Crossfade(tween(150)) + 指示器 animateDp，改动量最小。

代价：没有空间方向感，「从哪来、回哪去」读不出来；抽屉 fade 略显悬空。

B · 墨线轴线（推荐）

气质：向前一步就往上推、返回就下沉——方向感来自「轴」而非花哨，和编辑排印同频。

时值：tab fade-through 90+150 · 阅读器 24dp 上推 + 淡入 240 · 抽屉 250 · 指示器 200 · 星标 crossfade 120ms。

落地：M3 emphasized 曲线写成统一 MotionTokens，NavHost 六个目的地 + 六处 AnimatedVisibility 全部吃同一套 token，杜绝各写各的。

代价：需要先把 token 层建起来（一次性成本）；共享元素做不了，靠轴语义补偿。

C · 编辑编排

气质：杂志封面式编排——标题自己「走」进阅读器顶栏，正文段落随后依次落位。

时值：fly 260 · 顶栏延迟 340 · 正文 stagger 80 · 星标 pop 320ms。

落地：列表在 MainActivity、阅读器是独立 Activity，真共享元素成本高——需 overlay 伪造飞行层或合并 Activity。

代价：实现最贵；编排只能给低频路径（开文章/收藏），高频 tab 严禁编排，否则每天几十次会烦。

D · 流体纸页

气质：iOS 式跟手，一切有质量感；预览里用过冲曲线近似，真机用 spring 物理。

时值：无固定时长，spring stiffness≈300 / dampingRatio≈0.8，轻微过冲。

落地：Compose spring() 全量替换 tween；手势路径接 AnchoredDraggable。

代价：与 M17「抽屉去手势化」只兼容程序触发路径；过弹会和报纸的克制打架，参数必须收敛。

推荐 B · 墨线轴线：拨盘 5「有生命力但克制」的最优解——有方向性推进、有指示器滑动、有微反馈，全部收在 250ms 内的官方曲线里，Compose 落地成本最低。可混搭：B 骨架 + C 的星标 pop（写在确认弹层的调整框里即可）；也可以只取某个细节，在对话里告诉我。
