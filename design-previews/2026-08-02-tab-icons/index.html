方向说明（字体策略 / 设备落地 / 风险）

A · 衬线首字母（推荐）

气质：和刊头 34sp Fraunces、SourceRow 衬线 monogram 是同一套语言——底栏 icon 换成字母后，全 App 的「图形」统一成一种：衬线字形。

落地：零新资产——FrauncesFamily 已在打包，EditorialNavBar 把 Icon 换成 Text(字母, Fraunces 600)。语义：R=Reading / L=Library / A=Agent / S=Settings，与刊头英文小字一致。

代价：四个字母都直愣愣，个性靠字体本身；不如 B 有味道。

B · 花体手书

气质：铜板手写（copperplate）——四个字母各带飞白和游丝，底栏立刻有了「签名感」，是你提的方向里最浪漫的读法。

落地：Google Fonts 裁 R/L/A/S 子集 TTF（~30KB, 含 OFL 许可）入 res/font,同样替 Text。

代价：花体小字号下笔画细，24dp 可读性要在真机上验（尤其 L 和 S）；与 Fraunces 刊头是两种书法，混搭看接受度。

C · 印刷符号

气质：活版印刷的行话——¶（段落=阅读）、§（章节=文库）、❦（花饰=Agent 的「点缀智能」）、❧（叶饰=设置）。编辑梗最深，同好一眼懂。

落地：¶ § 是拉丁-1 基本符号，系统字体必有；❦ ❧ 在 Android 系统字体的覆盖要真机先验，缺字形就退回只打包含这几个符号的 Fraunces/字体子集。

代价：语义有门槛，新用户要猜；❦ 和 ❧ 造型偏近，扫读区分度一般。

D · 细线图形

气质：现行 Material 填充图标太「安卓默认」，细线化是最保守的提纯——还是那四个图形，但呼吸感对齐 hairline 体系。

落地：Material Symbols Outlined(weight 200)或自绘 SVG vector,零字体资产。

代价：最没性格，「任何一个阅读 App 都长这样」；与其这样不如不动。

推荐 A · 衬线首字母：零新资产、与 monogram 体系同源，是「本来就长这样」的连贯；但如果你想要底栏一眼有性格，选 B——它是你灵感的正解，代价只是 30KB 和一次真机可读性验收。混搭也可以：A 的骨架 + Agent 单独用花体 A（写进确认框）。
