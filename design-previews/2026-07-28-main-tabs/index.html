D仪表盘

Bloomberg 工具感 · 顶部统计带 + 直连/需代理状态徽章 · Barlow Condensed · 密度最高

推荐理由:A · 准线

理由
主界面是每天进出几十次的列表,亮色长时间看不累,与阅读器浅色主题衔接最自然;分隔线列表让密度与呼吸平衡,单一靛蓝重音足以建立识别度又不吵。
不选其他
B 的暗色与跟随系统的阅读器主题冲突大;C 的刊头气质建议借一点给 A 做页面标题;D 的密度适合数据产品,阅读工具会显得吵。
可混搭
也可以只要某个细节:在确认弹层的建议框里写,比如「要 A 的骨架 + C 的刊头标题」「A 但 monogram 换 D 的方块」。

A · 准线

气质
精确、安静、瑞士式的功能美
字体
Sora(西文 400/600/700)+ 中文系统栈;分组标签小号大写宽字距
色彩
纸白 #fafafa / 墨 #171717 / 靛蓝 #4f46e5 单点使用
记忆点
线框圆形 monogram + 小大写分组标签
落地映射
Compose:列表 Item + HorizontalDivider,单一 primary 色,NavBar 选中指示

B · 终端

气质
开发者工具、命令行式的效率感
字体
JetBrains Mono(源名/域名/计数全等宽)+ 中文系统栈
色彩
off-black #0d0d0f / 终端绿 #4ade80 / 琥珀 #f59e0b 标记代理
记忆点
~/sources 路径头 + 状态圆点 + 闪烁光标
注意
暗色硬编码会与系统深色/动态配色策略冲突,落地需全 app 配套暗色

C · 排印

气质
报纸刊头、国际主义平面、编辑物的手感
字体
Fraunces 衬线(刊头/组题)+ 系统无衬线正文 + 中文系统栈
色彩
纸白 #fbfaf7 / 墨 #141414 / 编辑红 #b3352b 仅一处
记忆点
「源 Sources」刊头 + VOL.03 期号 meta 行 + 双细线
适合
与英语学习/阅读内容气质最契合,可整方向采用或只借刊头

D · 仪表盘

气质
交易终端式的密度与状态可见性
字体
Barlow Semi Condensed + Barlow,数字 tabular-nums
色彩
冷灰 #f1f3f5 / 深青 #0e7490 / 绿橙状态语义色徽章
记忆点
统计带(源数/分组/直连数)+ 状态徽章体系
注意
密度最高,长时间浏览略吵;统计带可单独借给其他方向
